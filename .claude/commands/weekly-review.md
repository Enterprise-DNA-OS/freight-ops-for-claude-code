description: The Monday review, written from three commands. The compliance position, the freight, the money, and the five things that matter this week.
---

Run these three, in this order, and write the review from what they return. Do not write anything they do not support.

```
npm run freight -- attention
npm run freight -- compliance
npm run freight -- debtors
```

Then write it in this shape, no more than a page:

1. **The week in one line.** Open consignments, delivered this week, runs today, PODs missing, unbilled, owing, open claims, DIFOT (`stats` has all of it).
2. **The law first, always.** DG on the wrong driver, overloaded runs, work time breaches, COF, rego and RUC clocks. These lead the review because they are the lines an inspector reads.
3. **The service.** Late deliveries, freight stuck on no run, DIFOT by customer with the worst misses named.
4. **The money.** Missing PODs (with the blocked dollars), delivered-unbilled, overdue invoices, drafts never sent, anyone over their limit. One line each with the move.
5. **The claims.** Anything open, its age against the Act's windows, and the decision each one needs.
6. **The five things to do this week.** Picked from the attention list, weighted by what breaches first and what it costs, with why each made the list.
7. **One thing to decide.** The single item that needs a person, not a process.

Add `npm run view -- ops` and `npm run view -- money` if the operator wants pages to take to a meeting. They render the same numbers in the company's brand, and they print.

Numbers come from the commands. If a number is not in the output, it does not go in the review.
